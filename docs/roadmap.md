#### **Продолжительность:** 8 недель **Цели программы:**

- Освоить работу с NestJS/ExpressJS, PostgreSQL/MongoDB, Nodemailer.
- Разработать функционал: посты, лайки, комментарии, подписки, уведомления, реалтайм-чат.
- Настроить авторизацию через OAuth2.
- Научиться работать с базой данных и email-уведомлениями.
- Закрепить знания по TypeScript, ESLint и Prettier.
- Реализовать микросервисную архитектуру с вынесением сервиса аутентификации в отдельный сервис на ExpressJS.

---

### **Неделя 1: Введение и проектирование API**

- **Темы:**
  - Основы NestJS/ExpressJS.
  - Принципы REST API.
  - Проектирование структуры API.
  - Настройка линтинга (ESLint \+ pre-commit hook, Prettier) и TypeScript.
- **Задачи:**
  - Инициализация проекта.
  - Создание базового контроллера и маршрутов.
  - Настройка линтеров и форматтеров.
- **Практические задания:**
  - Спроектировать API для создания постов и пользователей.
  - Реализовать базовые CRUD-операции.
- **Ресурсы:**
  - Официальная документация NestJS.
  - Руководства по TypeScript.

### **Неделя 2: Работа с базой данных**

- **Темы:**
  - Настройка PostgreSQL/MongoDB.
  - Основы ORM (TypeORM/Mongoose).
  - Проектирование связей между сущностями.
- **Задачи:**
  - Настроить подключение к базе данных.
  - Реализовать модели для пользователей, постов и лайков.
  - Написать миграции для базы данных.
- **Практические задания:**
  - Создать таблицы/коллекции для постов, комментариев и пользователей.
  - Реализовать связи: пользователь — посты, пользователь — лайки.
- **Ресурсы:**
  - Документация PostgreSQL/MongoDB.
  - Примеры работы с TypeORM/Mongoose.

### **Неделя 3: Авторизация и регистрация (OAuth2)**

- **Темы:**
  - Основы аутентификации и авторизации.
  - Работа с OAuth2.
  - Введение в микросервисную архитектуру.
- **Задачи:**
  - Настроить отдельный сервис аутентификации на ExpressJS.
  - Реализовать регистрацию и вход через Google/Facebook в микросервисе аутентификации.
  - Настроить MongoDB для хранения токенов и данных, связанных с аутентификацией.
  - Настроить взаимодействие основного приложения с сервисом аутентификации.
  - Реализовать защиту маршрутов (Guard).
- **Практические задания:**
  - Подключить OAuth2 с использованием Passport.js в микросервисе аутентификации. (Реализовать 2 стратегии (Гугул и Гитхаб). ОДна из них должна быть сделана через Passport.Js, другая должна быть реализована самостоятельно)
  - Реализовать механизм refresh и access токенов.
- **Ресурсы:**
  - Документация Passport.js.
  - Примеры настройки OAuth2.

### **Неделя 4: Реализация функционала постов, лайков и комментариев**

- **Темы:**
  - Работа с контроллерами и сервисами NestJS.
  - Пагинация и фильтрация данных.
- **Задачи:**
  - Реализовать API для создания, редактирования и удаления постов. Необходимо организовать возможность загрузки картинок на сервер с использованием библиотеки Multer. Итоговую картинку необходимо хранить [MinIO](https://min.io/)
  - Настроить функционал лайков и комментариев.
  - Добавить пагинацию для списка постов.
- **Практические задания:**
  - Написать маршруты и тесты для CRUD операций с постами.
  - Реализовать возможность ставить лайки и оставлять комментарии.
- **Ресурсы:**
  - Официальная документация NestJS.

### **Неделя 5: Подписки и уведомления**

- **Темы:**
  - Механизм подписок.
  - Уведомления (push/email).
- **Задачи:**
  - Реализовать API для подписки на пользователей.
  - Настроить отправку уведомлений с Nodemailer \+ [React email](https://react.email/).
  - Сделать push нотификацию через websockets. В результате как только произошло событие, на которое подписан пользователь, ему на фронтенде должен отобразить [тост](https://ui.shadcn.com/docs/components/toast) в котором говорится о событии которое произошло.
- **Практические задания:**
  - Настроить модели для подписок и уведомлений.
  - Реализовать логику отправки email при новых подписках.
- **Ресурсы:**
  - Документация Nodemailer.
